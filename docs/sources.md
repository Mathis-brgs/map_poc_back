# Registre des sources

**Aucune source n'est branchée avant d'avoir sa fiche ici.** Chaque donnée stockée renvoie à une de ces fiches.

## Vérifications avant de brancher une source

- [ ] Licence identifiée, et lien vers son texte
- [ ] **Réutilisation commerciale** autorisée ? (oui / non / à vérifier) : décide de ce qui peut entrer dans une offre payante
- [ ] CGU lues
- [ ] `robots.txt` respecté, si collecte web
- [ ] Données personnelles (RGPD) : présentes ? Base légale ?
- [ ] Mention de citation exigée
- [ ] Format, fréquence de mise à jour, profondeur historique
- [ ] Référentiel territorial : code INSEE ? Quel millésime COG ?

## Rappels juridiques

- **Pas de texte intégral d'article de presse.** Le droit voisin des éditeurs impose leur autorisation. L'exception de fouille de textes et de données (art. L.122-5-3 du CPI) est écartée par l'opposition formelle des éditeurs (APIG, SEPM) depuis 2023.
- Presse publiée après 1951 environ : protégée 70 ans. Extraits et métadonnées seulement, sauf accord éditeur.
